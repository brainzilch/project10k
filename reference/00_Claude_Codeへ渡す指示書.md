# 市村記念体育館 コンサート設営・撤去 3Dアニメーション制作指示書

スマホだけで指示する場合は、同じフォルダの `00_スマホからClaude_Codeに貼るだけ.txt` の全文をClaude Codeに貼り付けてください。Drive素材にアクセスできない場合も実装できる座標・椅子配置・工程が含まれています。

このファイルと同じフォルダの `assets/` をClaude Codeが参照できる環境では、以下の詳細仕様に従ってください。

## 依頼内容

あなたは3Dアニメーション制作担当です。`assets/` にある市村記念体育館の平面図、現場写真、養生シート図、300席配置図、設営・撤去手順書を参照し、スタッフが作業順と完成形を理解できる3Dアニメーションを制作してください。実行可能なプロジェクト、ブラウザプレビュー、完成動画を納品してください。説明だけで作業を終えないでください。

### 最終成果物

- `dist/ichimura_setup_teardown_3d.mp4`：1920×1080、30 fps、約90秒、H.264、音声なし。日本語の画面内テロップで完結すること。
- `dist/poster.png`：全体配置を示す静止画。
- `README.md`：起動・プレビュー・動画書き出し・パラメータ変更方法。
- ソース一式：Three.jsなどを使った再現可能なプロジェクト。動画だけを納品しないこと。

長さや画角は設定ファイルから調整できるようにしてください。90秒は制作上の初期値であり、現地の実測値ではありません。

## 資料の優先順位

1. 作業順：`assets/setup_teardown_guide.pdf` と下記の確定手順。
2. 養生の位置・順・向き・折り返し：`assets/sheet_layout_clean.png`。`assets/sheet_layout_original_reference.png` は依頼者の元図で、形状照合用。
3. 楽器位置・客席：`assets/instrument_location_marked.png`、`assets/seating_300_overview.png`、`assets/seating_300_detail.pdf`。
4. 体育館の平面形状：`assets/floorplan_original.pdf`。`assets/floorplan_color.png` は視認用。
5. 室内の雰囲気：`assets/venue_wide.jpg`、`assets/venue_stage.jpg`。

図と写真が食い違う場合は、物の位置と作業順について1〜4の資料を優先してください。写真は雰囲気の参考であり、現在の展示物の正確な配置を示すものではありません。資料にない寸法・経路・展示物の形は事実として断定しないでください。

## 3D空間

- 平面図の向きを一貫して保ち、**ステージを画面左側**、養生図の「1」を下側、「4」を上側に置く。カット間で左右を反転しない。
- 体育館床、左側のステージ、客席を囲む建築形状、左右の観覧席、手すり、曲面天井を簡略化して立体化する。木質の床、赤系の観覧席、舞台幕の印象は現場写真に合わせる。
- 平面図の寸法線から基準スケールを読み、床・椅子・ピアノ・シートの相対サイズを揃える。読めない寸法を画像ピクセルから実寸と決めつけない。
- 演奏位置は赤丸の付いた図を基準に、ステージの手前側。ピアノとコントラバス等の象徴的な楽器を表示する。ピアノの型式・寸法は未確認なので、種類とサイズを設定で切り替えられる仮モデルにする。
- 「収納庫」の使用する扉と搬入経路は未確定。`storageAnchor` と `transportPath` を設定値にし、仮位置であることをREADMEに明示する。壁を貫通する移動を描かない。
- 中央の展示物は数・形が不明。ニュートラルな仮オブジェクトを使い、移動前に写真を撮って原状復帰の基準にする動きを重点的に示す。

## 確定した設営手順

1. 収納庫から養生シートを出す。
2. 体育館中央の展示物を**動かす前に**配置・向きを撮影し、展示物を収納庫へ移動する。
3. 養生シートを**1 → 2 → 3 → 4**の順に敷く。図の下から上へ、各帯は**右から左**に展開する。**シートは長いため、各帯の敷き終わりで余った長さを折り返す**。折り返しを省略せず、少なくとも1帯は寄りのカメラで動作が分かるように見せる。残りの帯も折り返しが完了した状態にする。色は識別用であり、実物のシート色を示すものではない。
4. 一般的な折り畳みパイプ椅子を**計300脚**設置する。既存参考図のA・B・Cに各100脚、演奏位置を囲む扇形配置。通路2本を見せる。椅子は幄460 mm×奥行500 mm、列間隔900 mm、席中心間隔520〜555 mmを**参考図作成時の仮定値**として扱い、実物・現地寸法と矛盾する場合は無理に詰め込まず報告する。
5. 収納庫からピアノを赤丸付近の定位置へ移動する。椅子を置いた後に行う順番を守る。ピアノの通過経路は未確定なので、設定可能な安全な仮経路で示す。

養生完了後に「土足作業可」と表示する。養生前の競技床面で土足のスタッフが作業しているように描かない。

## イベント終了後の撤去手順

設営と逆順にする。画面にも明確に番号を出す。

1. ピアノを収納庫へ戻す。
2. 椅子300脚を撤去する。画面上のカウンターを300→0にする。
3. 養生シートを**4 → 3 → 2 → 1**の順に回収し、まとめる。
4. 展示物を収納庫から中央へ戻し、設営前に撮った写真と見比べて位置・向きを復旧する。
5. まとめた養生シートを収納庫へ戻す。

## 表現と実装

- 画面内の日本語を大きく読みやすく。各工程名・番号・完了した椅子数を表示する。番号だけを色に頼らせない。
- 椅子は金属パイプ脚・座面・背もたれのあるモデルとし、可能なら `InstancedMesh` で300脚を軽く描画する。客席の向きは演奏位置へ向ける。
- シートは床に近い薄いメッシュで、展開する長さと折り返した上層が立体的に分かるようにする。シートの長さ・幅・折り返し量は `config` の変数にする。実寸は未提供なので映像用の仮値を置き、READMEに列挙する。
- アニメーション時刻 `t` に対し場面状態を決定的に計算できる構造にする。ランダム値は固定シード。ブラウザで任意の時刻にシークできるようにする。
- Vite + Three.jsを基本構成にし、プレビューに再生・一時停止・シーク・カメラ切替を用意する。動画はブラウザをフレームごとに描画して `ffmpeg` でH.264にするなど、同じタイムラインから再現可能に書き出す。
- 外部の未許諾3Dモデルや写真を勝手に取得しない。付属素材と自作形状を使う。参考写真は模写の方向付けであり、画面に無断転載して背景に貼り付けない。

## 検証と納品条件

- 椅子オブジェクト数が**300**、A/B/Cが**各100**であることをコード上のチェックで確認する。
- シート敷設は1→4、撤去は4→1。敷き終わりの折り返し動作が実際に画面で確認できること。
- 展示物は移動前に写真撮影し、撤去時にその写真を参照して原状復帰すること。
- ピアノ搬入は椅子300脚設置後、搬出は椅子撤去前であること。
- 椅子が演奏位置や通路、壁にはみ出さないことを上面図で検査する。寸法が確定しない部分は「仮配置」と明示する。
- 0秒、シート折り返し、150脚設置時、完成時、撤去後のフレームを確認し、文字切れ・オブジェクト貫通・ちらつき・床の透過不良がない状態にする。
- `ffprobe` で最終MP4の1920×1080・30 fpsを確認する。READMEに未確定事項と調整した設定値を残す。
