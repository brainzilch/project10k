# 市村記念体育館 コンサート設営・撤去 3Dアニメーション

Vite + Three.js で作成した、約90秒の設営・撤去手順の 3D アニメーションです。
ブラウザでの再生・シーク・カメラ切替ができるプレビューと、同じタイムラインから書き出した
1920×1080・30 fps・H.264 の MP4、ポスター画像、検証用フレームを含みます。音声はありません。

> **注意**：会場の寸法・養生シートの実寸・収納庫の位置と経路・展示物の実物・ピアノの型式は未確定です。
> 映像内の値は「仮値」で、現地実測値ではありません。すべて `src/config.js` で変更できます（後述）。

## 完成物の閲覧方法

1. **動画をそのまま見る**：`dist/ichimura_setup_teardown_3d.mp4` を開く（スマホでも再生できます）。
2. **ブラウザでプレビュー（再生・シーク・カメラ切替）**：

```bash
npm install
npm run dev        # http://localhost:5173 を開く
```

- ▶ 再生／一時停止（スペースキーでも可）、シークバーで任意の時刻へ移動（←→で1秒、Shift+←→で5秒）
- カメラ：自動（タイムライン）／斜め俯瞰／真上／自由（ドラッグで回転・ホイールで拡大）
- 速度：0.5×／1×／2×、「画面保存」で現在の画面を PNG 保存

ビルド済みの静的ファイルを配信する場合は `npm run build && npm run preview`（http://localhost:4173）。

## 動画・画像の書き出し手順

必要なもの：Node.js 18 以上、`ffmpeg`（libx264 対応）、Chromium（Playwright のもの、または `CHROMIUM_PATH` で指定）。

```bash
npm install
npm run verify:seating   # 椅子 A/B/C 各100脚・計300脚、通路、床範囲を検証
npm run build            # dist/web にビルド
npm run render           # ヘッドレス Chromium で 2700 フレーム描画 → ffmpeg で MP4（約 20〜30 分）
npm run verify:video     # ffprobe で 1920×1080・30 fps・H.264・90 秒を確認
node scripts/poster.mjs  # dist/poster.png
npm run checks           # dist/checks/ に検証用フレームを書き出し
```

環境変数（任意）：`CHROMIUM_PATH`（Chromium 実行ファイル）、`OUT`（出力先）、`START`/`END`（秒、部分書き出し）、`CRF`（画質、既定 18）、`FFMPEG`、`PREVIEW_PORT`。

書き出しは `src/timeline.js` の `computeState(t)` が時刻から場面を決定的に計算するため、何度書き出しても同じ動画になります（乱数不使用）。
プレビューの `?capture=1` モードを Playwright で開き、各フレームで `window.__anim.setTime(t)` を呼んでスクリーンショットを ffmpeg に流し込んでいます。

## 3D 空間と座標

- 画面左（-x）がステージ、右（+x）が体育館床。z- が平面図の上（養生図の「4」側）、z+ が下（「1」側）。カット間で左右は反転しません。
- 上手・下手：客席からステージに向かって右が上手＝図の上側（z-）、左が下手＝図の下側（z+）。収納庫は上手側の壁にあります。
- 平面図を幅 2000 px に縮小した作図座標で、演奏位置の中心 (773, 667) を原点にとり、`x = (planX − 773) / 15.85`、`z = (planY − 667) / 15.85` [m] としています。
  15.85 px/m は作図上の概算で、元図 `floorplan_original.pdf` の寸法線（通り芯 1〜14 の合計 66,000 mm ≒ 約 2,060 px）から検算すると約 15.6〜15.85 px/m で整合しました。現地実測値ではありません。
- 床の範囲・ステージ前縁の曲線・観覧席・曲面天井は平面図と現場写真から簡略化して立体化した「仮の形」です。
- 真上視点は `up = (0,0,−1)` で、平面図と同じ向き（上が「4」、下が「1」、左がステージ）になります。

## 検証結果

- `npm run verify:seating`：A=100、B=100、C=100、合計 300。席中心間隔 0.519〜0.554 m（参考 0.52〜0.555）。通路（−35〜−25°、25〜35°）に椅子なし。床・ステージ・演奏位置半径内にはみ出しなし。
- `src/props.js` の `buildChairs()` でも起動時に同じ検証を行い、失敗すると例外で停止します。
- `npm run verify:video`：最終 MP4 が 1920×1080・30 fps・h264・約 90 秒であることを確認（結果は本 README 末尾）。
- `dist/checks/`：0 秒／シート折り返し途中（寄り）／150 脚／完成／撤去後／真上／斜め俯瞰 の各フレームで、文字切れ、壁の貫通、床とシートの干渉、天井による遮蔽がないことを目視確認済み。
  - カメラが建物の南側（帯 1 側）の外にあるときは、その側の壁・観覧席を非表示にして内部を見せています。天井はカメラが天井より上のときのみ非表示です。

## 音について

- **Suno は使っていません**。私の実行環境から Suno（外部の音楽生成サービス）を操作できないためです。BGM と効果音は `src/staff/audio.js` で合成した自作の音です（毎回同じ音になります）。
- 効果音: 場面転換、手順のチャイム、足音、ドア、開場チャイム、ささやき声、ブザー（ぶぶーっ）、拍手、終わりのチャイム。公演中（58〜77秒）は生音に近い静かなピアノの生演奏だけになります。
- Suno で作った曲に差し替える方法と指示文は `audio/README_suno.md` にあります。`audio/bgm.mp3` を置いて書き出しを実行するだけです。
- 「音声あり」を BGM の意味と解釈しています。ナレーション（読み上げ）は入れていません。
